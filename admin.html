Add login

Use the name exactly as it appears on bills (Delivery Partner, Sales Person or a collection visit's “Assigned To”). Whenever a bill or visit is assigned to that name, even before the login exists, it shows up in this person's login: Delivery Details for bills they deliver, Signed Bills for collection visits assigned to them. The Login ID is filled in from the name (you can change it): letters followed by exactly 4 digits.

Edit login

Bills are matched to a person by name, so use the name exactly as it appears on bills (for example “Sunil Garg”). If the old name is already on bills or collection visits, you'll be asked whether to move them to the new name too. The password is not changed here (use “Reset password”). If you change the Login ID, tell the person their new ID.
